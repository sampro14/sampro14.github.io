AgentEval.

Finds where an agent run went wrong, why, and whether it recovered. Every run is recorded as a trajectory with per-step output, latency and tokens.

  • Execution is the ground truthSeven agents from plan to repair. Generated code runs in a locked-down Docker sandbox with no network.
  • Every failure gets an ownerA rule-based classifier, with an LLM fallback, names the failure category and the agent responsible.
  • The evaluator is tested too16 planted bugs it must catch and attribute, and 6 clean controls it must pass, across Anthropic, OpenAI, Gemini and DeepSeek.
